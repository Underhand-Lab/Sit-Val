# 현재 앱 상태

- 리그분석
    - 리그의 타격 스탯과 평균 주자 능력을 입력하면 다양한 정보 계산
        - RE24, 한 이닝당 x점 이상 득점 확률, 해당 리그 개인 성적 입력시 해당 선수의 확장 가치 계산(wRAA, wRC+), 리그 확장 가치, 9이닝당 평균 득점
- 라인업 분석
    - 타자의 타격 스탯, 타자 배ㅊ, 리그 평균 주자 능력을 입력하면 다양한 정보 계산
        - 타선 시점별 RE24, 타선 시점별 x점 이상 득점 확률, 9이닝당 평균 득점

# 변화

- db 도입
    - firebase 또는 supabase
    - 테스트용으로 local storage 사용 가능
- 각각의 정보 등록
    - 리그(DB)
        - 연도별 리그(DB)
            - 타격 스탯 + 타점 + 득점 + 연도 + 리그 외래키
    - 팀(DB)
        - 연도별 팀(DB)
            - 타격 스탯 + 타점 + 득점 + 연도 + 연도별 리그 외래키 + 팀 외래키
    - 선수(DB)
        - 연도별 선수(DB)
            - 타격 스탯 + 타점 + 득점 + 연도 + 연도별 팀 외래키(여러개 가능(이적 고려)) + 선수 외래키
    - 타격 스탯에 포함되는 항목 BatterStats.ts의 항목
- 각각의 분석 기록 보기
    - 리그 분석
        - 해당 연도의 확장 스탯(현재 앱 상태의 리그 분석 내용)
    - 선수 분석
        - 리그가 등록된 경우 현재 앱 상태의 리그 분석의 해당 선수 확장 가치 계산 기능 시각화
        - 없는 경우 스탯만 보여줌
    - 라인업 분석
        - 등록된 선수 불러오기 가능
        - 라인업은 DB 저장 x

제가 원하는 형태는 아래와 같습니다.

- 선수, 리그, 팀 등을 검색
    - 해당 정보를 선택하면 특화 기능에서 상세 정보를 보여줌
- 선수 정보와 리그에서는 아래 기능
    - 편집을 누르면
        - 현재 시스템과 같이 각 스탯의 변화에 따른 확장 가치 변화 관찰 가능
    - 그외
        - 해당 확장 가치를 예쁘게 보여줌
- 선수 정보
    - 선수에게 리그가 등록되어 있다면 현재 리그 페이지의 PersonlVisualizer 위주로 보여줌
- 팀 정보에는 현재 라인업 구성 기능 제공
    - 편집을 눌렀을 때
        - 라인업 편집을 누르면 현재의 라인업 페이지와 동일
    - 그외
        - 선수만 등록된 상태라면 선수 편집 활성화
        - 라인업도 등록된 상태라면 확장 가치를 예쁘게 보여줌
